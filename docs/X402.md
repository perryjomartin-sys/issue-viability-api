# x402 payment guide

`POST /v1/check` uses x402 V2 on Base mainnet. One assessment costs **$0.005** in native Base USDC.

| Field | Value |
| --- | --- |
| Network | `eip155:8453` |
| Scheme | `exact` |
| Asset | `0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913` |
| Amount | `5000` base units |
| Resource | `https://issue-viability-api-mainnet.agentactiongateway.workers.dev/v1/check` |

The API intentionally does not embed a wallet or browser paywall. An x402-capable client sends an ordinary request first, reads `payment-required` on HTTP `402`, decides whether its payment policy allows the charge, then creates and submits a payment according to the x402 protocol. The API verifies a paid request through the configured Coinbase facilitator before assessment.

Do not send a private key, Coinbase credential, or payment material to this repository or in a request body. The payment authorization belongs in the client-generated x402 header only after the client has approved the charge.

Production Base-mainnet x402 challenge and Coinbase facilitator authentication are verified. Settlement and replay protection have been validated end-to-end on Base Sepolia.
